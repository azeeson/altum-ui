# Dist demo

Страница для ручной проверки компонентов на **собранной** библиотеке (`dist/`), а не на исходниках из `src/`.

## Запуск

Из корня репозитория:

```bash
npm run build
npm run demo
```

Откроется Vite на http://localhost:5173.

После правок в `src/` снова соберите `npm run build` и обновите страницу (HMR не подхватывает пересборку `dist` автоматически).
